# Aether for macOS

Release artifacts and the auto-update feed for the Aether desktop app, which hosts [app.runaether.dev](https://app.runaether.dev) in a native window.

The app's source lives in Aether's main repository; this repository only publishes releases. Each release carries an Apple Silicon and an Intel installer, both signed and notarized, plus the manifest the installed app reads to update itself.
